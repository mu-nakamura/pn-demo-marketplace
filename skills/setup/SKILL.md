# setup：デモの準備

pn-demo のデモ用に、作業フォルダへ架空の入力ファイルを置く。実在の会社名・数値は使わない。

## 手順

1. 現在の作業フォルダ（チャットの作業ディレクトリ）に、次のディレクトリがあるか確認する：`inputs/`、`drafts/`、`records/`。
2. 無いディレクトリは作る。
3. 次の3ファイルを、**無い場合だけ**、下記の内容そのままで作る。**既にあるファイルは上書きしない**（あれば「既にあるため触っていません」と報告する）。
4. 最後に、次を短く報告する：作ったもの、作らなかったもの（既存）、`records/` の現状（項目が無いか、既存の記録があるか）。次の一手として「新しいチャットで `/pn-demo:conductor` から始める」ことを案内する。

## `inputs/kita_notes.md`

```markdown
# 北精機（架空）入力メモ

- 北精機（架空）。産業機器メーカー。主力は工作機械の製造販売で、保守契約の更新率は高い。
- 経営企画の課題：来期の重点投資を役員会で決める。
- 候補テーマ：A 保守サービスの強化／B 海外新市場の開拓／C 工場の自動化投資。
- 判断基準：投資回収の見通し／実行リスク／既存事業との相乗効果。
- 来期の投資予算の上限は、財務に確認中。
```

## `drafts/board_v0.md`

```markdown
# 来期 重点投資テーマ 検討資料（役員会向け）v0

作成：先行担当の下書き（古い版）

## 目的

来期の重点投資テーマを1つ決め、役員会の承認を得る。

## 候補テーマ

- A 保守サービスの強化
- B 海外新市場の開拓
- C 工場の自動化投資

## 判断基準

投資回収の見通し／実行リスク／既存事業との相乗効果。

## 結論（案）

来期の重点テーマは B（海外新市場の開拓）とする。

## 前提

来期の予算枠は3億円。

## 次の行動

役員会に向けて、実行計画の骨子を作る。
```

## `records/index.md`

項目の無い、空の一覧。conductor が開始時に読んで「記録はまだありません」と判断できるようにするための置き場（ファイルが無いと、読み込みが失敗として画面に出るため）。

```markdown
---
okf_version: "0.2"
---

# 北精機 経営企画 判断記録（デモ用・架空）

# 決定

（なし）

# 前提

（なし）

# 未決

（なし）
```

## 注意

- このスキルが `records/` に置くのは、上の空の `index.md` だけ。記録（決定・前提・未決・`log.md`）は conductor が人の同意を得て作る。
- ファイルを削除しない。やり直したいときは `/pn-demo:reset`（退避して初期化）を使う。
